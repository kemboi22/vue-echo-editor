These docs publish the [llms.txt](https://llmstxt.org) standard files so AI assistants can learn Echo Editor without scraping HTML.

| URL | Contents |
| --- | --- |
| [`/llms.txt`](/llms.txt) | Index of every page with a one-line description, grouped by section, plus the MCP endpoint. |
| [`/llms-full.txt`](/llms-full.txt) | The complete documentation in one Markdown file. |
| `/raw/<path>.md` | Any single page as clean Markdown, e.g. [`/raw/guide/markdown.md`](/raw/guide/markdown.md). |

## Using it

- **Chat assistants** — paste the `/llms-full.txt` URL (or its contents) into the conversation: *"Using https://echo-editor.dev/llms-full.txt, add a Markdown editor to my Vue app."*
- **Cursor / Windsurf** — add `https://echo-editor.dev/llms-full.txt` as a docs source (`@Docs → Add new doc`).
- **Claude Code / agents** — point them at `/llms.txt`; they can follow the links to the raw Markdown pages. Better still, connect the [MCP server](/ai/mcp).

## How it's generated

The files are built from the same Markdown that powers this site, using [`nuxt-llms`](https://github.com/nuxt-content/nuxt-llms) with a small Nitro plugin that walks the `content/` directory. They are prerendered at build time, so they are always in sync with the docs.
