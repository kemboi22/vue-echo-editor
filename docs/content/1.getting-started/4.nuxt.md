Echo Editor is a browser component (it needs the DOM for ProseMirror), so render it on the client.

::steps

### Install

:pm-install{name="vue-echo-editor"}

### Add the styles

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  css: ['vue-echo-editor/style.css'],
  build: {
    transpile: ['vue-echo-editor'],
  },
})
```

### Create a client-only component

Name the file with a `.client.vue` suffix, or wrap the editor in `<ClientOnly>`:

```vue [components/RichEditor.client.vue]
<script setup lang="ts">
import { EchoEditor, BaseKit, History, Heading, Bold, Italic, Link, BulletList } from 'vue-echo-editor'

const model = defineModel<string>({ default: '' })
const extensions = [BaseKit, History, Heading, Bold, Italic, Link, BulletList]
</script>

<template>
  <EchoEditor v-model="model" :extensions="extensions" />
</template>
```

### Use it

```vue [pages/index.vue]
<script setup lang="ts">
const content = ref('<p>Hello from Nuxt</p>')
</script>

<template>
  <RichEditor v-model="content" />
</template>
```

::

## Rendering stored content on the server

To display saved documents during SSR (for SEO or a read-only view) you do not need the editor. Render the stored HTML inside an element with the `EchoContentView` class so it gets the editor's typography:

```vue
<template>
  <div class="echo-editor echo-editor-ui">
    <div class="EchoContentView" v-html="article.html" />
  </div>
</template>
```

::alert{type="warning" icon="lucide:shield-alert"}
Always sanitize user-generated HTML on the server (for example with DOMPurify or `sanitize-html`) before rendering it with `v-html`.
::

## Colour mode

Pass Nuxt's colour mode to the editor so it follows your site theme:

```vue
<script setup lang="ts">
const colorMode = useColorMode()
</script>

<template>
  <EchoEditor :dark="colorMode.value === 'dark'" :extensions="extensions" />
</template>
```
