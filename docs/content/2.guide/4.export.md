## Toolbar button

```ts
import { Export, Markdown } from 'vue-echo-editor'

const extensions = [
  BaseKit,
  // …
  Markdown, // enables the Markdown option
  Export.configure({
    formats: ['pdf', 'markdown', 'html', 'text', 'rtf', 'json'],
    filename: () => `notes-${new Date().toISOString().slice(0, 10)}`,
  }),
]
```

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `formats` | `ExportFormat[]` | all | Formats shown in the dropdown, in order. |
| `filename` | `string \| () => string` | `'document'` | File name without extension. |

## Formats

| Format | How it works |
| --- | --- |
| `pdf` | Opens the browser print dialog with a clean, styled copy of the document — choose **Save as PDF**. No extra dependencies. |
| `markdown` | `editor.getMarkdown()` — requires the `Markdown` extension. |
| `html` | A standalone HTML file that embeds the editor's content styles. |
| `text` | Plain text with blank lines between blocks. |
| `rtf` | Rich Text Format (headings, bold/italic/underline/strike, sub/superscript, lists, task lists, quotes, code, tables). Opens in Word, Pages and LibreOffice. |
| `json` | The Tiptap/ProseMirror JSON document — lossless. |

## Programmatic export

```ts
// Through the command (downloads a file)
editor.commands.exportDocument('markdown', 'my-notes')

// Or get the content without downloading
import { serialize, jsonToRTF, toPlainText, downloadFile } from 'vue-echo-editor'

const { content, mimeType, extension } = serialize(editor, 'rtf', 'report')
await fetch('/api/documents', { method: 'POST', body: content, headers: { 'content-type': mimeType } })
```

## Word (.docx)

DOCX export needs a heavier converter, so it's not built in. The [examples app](https://github.com/kemboi22/vue-echo-editor/tree/main/examples/extensions/ExportWord) contains a complete `ExportWord` [plugin](/api/plugins) built with `prosemirror-docx` that you can copy.
